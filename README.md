# Integer Indexed Priority Queue
A high-performance priority queue (supporting either a minimum or maximum priority, depending on the comparison function) implemented as a binary heap with optimized key-modification operations ("decrease" and "increase"); it is based on the TIPQ class developed by Rassim Eminli. (http://c-evo.org/files/download.php?remi.remi.zip)<br>
Other project features:<br>
An implementation of an abstract game AI is provided as an example, which dynamically adjusts task priorities based on the state of the game.
